v2c 遗留三伤口：rep-4 0.135（reason 0.728 / en-fluency 0.708 / zh-fluency 0.516 三题长答案复读）、translate-en2zh 英答英、math-mul 非纯数字。两轮侦察（`/tmp/v2d_recon{,2}.py`，口径 = build 主数据流 + 前 810k 行预算截断）：

三条读数决定改动面：
1. **复读三题的题型 = 引导型短 prompt**（介绍/假设/tell me about），训练答案 p50≈600~700 字符——长答案先验超出 140M 的长文连贯能力；**泛开放问答池（27 万条）不碰**（v2 rep-4 0.066 时它们就全量在，不是新增变量）。
2. **英文长答案几乎不在训练集**（≥1000 字符写入 0 条 @810k）——en-fluency 的英文复读是中文长答案先验的泛化，英文侧**砍不到、只能加正例对冲**（concise 英文组）。
3. **英→中池仅 608 条（0.22%）** vs v2c 英→英上采样 32,754 条——方向先验被淹没；且池内是"英问中答"杂样，**没有"翻译指令 → 直接译文"的精确格式样本**（这一点在结果里变成了新伤口，§5）。

## 2. 四规则（`build_sft_v2.py` 新参数，v2c 规则全沿用）

| # | 参数 | 内容 | 写入量 |
|---|---|---|---|
| ① | `--long-answer-keep-den 2` | 引导型长答案（prompt<120 字 ∧ 答案≥600 字 ∧ 非列表/数学/翻译题）保留 1/2 | seen 12,803 → 砍 6,507 / 留 6,296 |
| ② | `--translate-upsample 3` | 英 prompt→中 answer 非列表样本 3× | seen 702 → 写入 2,106（v2c 544） |
| ③ | `--concise-repeat 3` | concise 连贯正例（50 条 ×3：中文介绍 20 + 中文假设 10 + **英文 fluency 20**，2~3 句无编号行） | 150 |
| ④ | `--format-repeat 3` | format 补充样本 2→3× | 1,978 → 2,967 |

对账（vs v2c）：token/block 完全同预算；数学豁免 6,264 保持（eqrows≥3 口径不动）；列表 10.55%→10.15%；长答案砍 6,507 ≈ 省 2.9M token、②③④ 增 ~2.3M → n_read 延后 ~4%，v2c 各 seen/kept 类目微增（calib 3,039→3,158 / en_helpful_up 16,377→18,650）。**改规则 = 改训练分布**，对账已入 `data/PROVENANCE.md` v2d 节。

**v2d 逐题要点**：
- math-add：输出 **"8"**（纯数字！v2c 是"3 加 5 等于 8"）——`--format-repeat 3` 修好了格式跟随。
- math-mul：**"7 乘以 6 等于 72"**——退回 v2 的同款错误值（v2b/v2c 都是 42）。
- translate-en2zh：英答中但内容是字词解释（"我的翻译是'我'在中文中是'我'的意思…"）——方向修了一半、**翻译行为没学会**（rubric 过 / 关键词不过，且该题 rep-4 0.293 是 v2d 的新最大单项）。
- list-3：编号项只有 2 条（rubric ❌，要 3 条）。
- refuse-unknown：输出"2027 年没有世界杯…没有冠军"（**正确**）——关键词 expect_any 缺"没有"判 ❌（已知假阴，rubric ✅）。
- capability/en-fluency：质量最佳（"我是由个人开发者独立开发的minimind…"；英文正文不再拒答）。

## 6. 新教训（入 `notes/lessons.md`）

1. **组合记忆在容量边缘，微小分布扰动就翻转**：7×6=42 在 v2b/v2c 稳定，v2d 仅净增 ~2.3M token 杂样（数学豁免量 6,264 不变）即退回 v2 的"72"（= 6×12 的强先验干扰）。**单题组合修复的稳定性要用"多版小扰动"验证，不能凭一版判决。**
2. **"方向池上采样"教不会"指令行为"**：英→中杂样上采样 3× 只改变"英 prompt → 中文回应"的泛化，不教"把 X 翻译成中文 → 直接给译文"的精确行为；v2d 输出变成"英文原句 + 中文字词解释"。**行为修复要用目标行为的精确样本（指令+直接答案），不是同方向的泛化样本。**
3. **英文长答案缺席时，英文复读只能靠加正例对冲**：训练集英文 ≥1000 字符写入 0 条，en-fluency 的复读是中文长答案先验的跨语言泛化——concise 英文组把该题 rep-4 砍到 0.371（仍高于 v2 0.306，因为 v2 靠"短答案"整体回避）。
