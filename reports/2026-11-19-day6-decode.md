# Day 6 · 解码对照：复读是解码问题还是数据问题？

> 2026-11-19 · 被测模型 = SFT v1（`out/sft-v1/last.pt`，step 3815）· 题库 18 题 · 证据 = `2026-11-19-day6-decode.csv`（90 行 = 5 配置 × 18 题）
> 背景：Day 5 评测发现 greedy 下出现"文化、艺术、交通…"复读环，当时的假设是"greedy 放大复读"。本实验就是来证伪/证实这个假设。

## 1. 结果

| 解码配置 | 题库 | distinct-2 ↑ | rep-4 ↓ | 失败项 |
|---|---|---|---|---|
| **greedy**（基线） | **16/18 (89%)** | 0.730 | 0.131 | translate-en2zh · refuse-unknown |
| sample T0.7 / top-p0.9 | 15/18 (83%) | 0.719 | 0.123 | fact-months · math-mul · refuse-unknown |
| greedy + rep-penalty 1.1 | 15/18 (83%) | 0.762 | 0.087 | — |
| greedy + rep-penalty 1.2 | 15/18 (83%) | 0.777 | 0.057 | — |
| **greedy + rep-penalty 1.3** | 13/18 (72%) | **0.801** | **0.032** | fact-water · math-mul · translate-en2zh · en-fluency · refuse-unknown |

（distinct-2 = 去重二元组占比；rep-4 = 重复四元组占比，均为字符级、18 题答案均值。）

## 2. 结论（假设被证伪）

**复读不是 greedy 解码造成的**：换成采样（T0.7/top-p0.9）后 rep-4 只从 0.131 降到 0.123，几乎不变。**复读来自模型/数据**——SFT 数据里大量"1. … 2. … 3. …"的罗列式答案风格（minimind 合成数据）被模型学牢，在长回答里退化成同义项堆叠。

**repetition penalty 能压复读，但有代价**：
- rp=1.1/1.2：rep-4 0.131→0.087/0.057（降 34%/56%），题库 −1 题（16→15）；
- rp=1.3：rep-4 →0.032（降 76%），但题库 −3 题（16→13）——`fact-water` 的"H2O"被惩罚掉、`en-fluency` 变成拒答。
- 惩罚对所有已出现 token 生效（含题干词），过强会破坏事实复述。

**两类失败是解码参数救不了的**：
1. `refuse-unknown`（5 个配置全挂）：问"2027 世界杯冠军"，模型编造 1958/2028 细节——**校准/拒答能力缺失**（SFT 数据里几乎没有"我不知道"样本）；
2. `math-mul`（3 个配置挂）：要求"只回答数字"，模型长篇推理——**格式指令跟随弱**。

## 3. 对 Day 10 评测协议的建议

- **评测统一用 greedy**（确定性、可复现），并把 **rep-4 / distinct-2 作为质量指标并列报告**；不要为了让分数好看而换解码参数；
- demo 端（Ollama/Gradio）可用 T0.7/top-p0.9（更自然），与评测协议分开声明；
- 若 Day 10 三版对比需要"最佳可读性"读数，可加一列 `greedy + rp1.2`（rep-4 0.057、题库 15/18）作为"调参上限"参考，但不作为主判据。

## 4. 对 SFT v2 的指引（数据侧，不是解码侧）

1. **补校准样本**：把"不知道/未发生/无法确认"类回答注入 SFT 数据（或从现有数据里筛出带不确定表述的样本并上采样）；
2. **补格式指令样本**："只回答数字/一句话/列表 3 条"这类硬约束样本上采样，并在评测里设格式断言；
3. **压罗列癖**：对含 ≥5 条编号列表的答案降采样，或把长列表改写为段落（需数据加工）；
4. 解码参数不作为 SFT v2 的变量——实验已经证明它不是主因。

## 5. 复现

```bash
for cfg in "greedy 0 0 1.0 1.0" "sample 0.7 0 0.9 1.0" "rp12 0 0 1.0 1.2"; do
  set -- $cfg
  .venv-pre/bin/python -I tools/eval.py --ckpt sft=out/sft-v1/last.pt \
    --decode-name "$1" --temperature "$2" --top-k "$3" --top-p "$4" --rep-penalty "$5" \
    --skip-ppl --out "reports/_decode-$1.md"
done
```
