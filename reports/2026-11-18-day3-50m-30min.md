# Day 3 · 50M 30 分钟吞吐跑（决策门①预注册动作）

> 2026-11-18 · 预注册出处：PLAN §4.1「50M 配置跑 30 min 测吞吐（同时验证管线/显存/稳定性）」· 证据三分 = 本件 + `2026-11-18-day3-50m-30min.csv` + `2026-11-18-day3-50m-30min.log`

## 1. 配置

| 项 | 值 |
|---|---|
| 模型 | d576 / L8 / H9（head_dim 64）· **50,292,288** 参数（non-emb 31,860,288）· vocab 32,000 tied |
| 序列 / 批量 | T=1024 · micro-bs 16 × grad-accum 4 = **65,536 tok/step**（与主训练同口径） |
| 优化 | AdamW(fused) lr **6e-4** · warmup 500 · cosine→10% · wd 0.1 · clip 1.0 · bf16 autocast |
| 数据 | `data/shards/` 6 片 3B token（en:zh=6:4）+ 固定 val 窗口 |
| 记录 | eval 500 步（20 iters × bs16）· sample 1500 步 · ckpt 1000 步 · `--max-minutes 30` |

## 2. 读数

| 项 | 值 |
|---|---|
| 步数 / token | **3,292 步 / 215,744,512 token**（0.65 epoch） |
| 墙钟 | 30m01s（其中 eval/sample/ckpt 开销仅 **11s = 0.6%**） |
| **纯训练吞吐** | **120,517 tok/s**（窗口读数全程 118k~123k，无衰减） |
| 6N 口径有效算力 | **36.4 TFLOPS**（6 × 50.29M × 120,517）——Day 1 字符级 22M 为 24.9 TFLOPS，T=1024 + bs16 更喂满 |
| 峰值显存 | 10.72 GB（含常驻 1.78GB）· GPU 58°C / 98% util / SM 2797 MHz（无降频） |
| loss / val | 10.4731 → 3.5928（train 窗口）；val **5.2162@500 → 4.2556@1000 → 3.8304@2000 → 3.6377@3292**（单调下行，无尖峰、无发散） |
| 退出 | `EXIT:0 step=3292 val=3.6377 tps=120517 stop=max_minutes(30.0)` |

## 3. 采样进化（固定 prompt，temperature 0.8 / top_k 200 / 60 new tokens）

- **step 1000（65.5M token）**：中英均为通顺短语拼接，语义漂移明显。
- **step 1500（98M token）**：中文已能整段组织（"人工智能是'人工智能和机器学习'等学科领域的技术。在这篇文章中，我将探讨…"）；英文有句式但史实错乱。
- **step 3000（196M token）**：中文段落结构完整（列举"医疗保健、金融、交通、通信"），**史实错误仍在**——"中国的首都是洛杉矶"、"The capital of France is the most famous country"。与 PLAN §1 预期管理一致：50M/2 亿 token 只买到"通顺"，买不到"知识"。

## 4. 预注册判据对账

| 判据 | 门限 | 实测 | 结论 |
|---|---|---|---|
| 50M 交叉校验门限（等价 140M 35k，FLOPs 比 2.74×） | ≥96k tok/s | **120,517** | ✅ 通过（按 2.74× 折算 ≈ 44.0k @140M） |
| 稳定性（30 min 无中断/无尖峰/无降频） | 全程稳定 | loss 单调、58°C、98% util | ✅ |
| 显存（16GB 卡含常驻） | 不 OOM | 峰值 10.72 GB | ✅ |
| 采样可用性 | 非乱码/非复读 | 中文成段；事实错误（预期内） | ✅（质量留主模型） |

**与 140M 探针的关系**：本跑的 44.0k 折算值是"同 MFU"假设下的**保守下界**，140M 实测 52.3k（见 `2026-11-18-day3-140m-probe.md`）——大模型反而更划算，原因见 `notes/qa-day-3.md` 题 3（词表投影/softmax 的每-token 固定成本在 50M 里占比更大）。
