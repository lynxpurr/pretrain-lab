## 1. 开工发现：评测污染（本轮最大收获）

核对 18 题原句 vs `data/sft-extra-v2/` 五类 extras 时发现**系统性同题样本**（不是 v2d 独有，v2 起就有）：

| 评测题 | 撞车样本（版本） | 后果 |
|---|---|---|
| refuse-unknown "2027 世界杯冠军" | calibration **完全一致**（v2 起） | v2~v2d 的 refuse "过" = 记忆原题 |
| math-mul "7 乘以 6…只回答数字" | format ARITH 模板 **完全一致**（v2 起） | math-mul 42 的修复 = 部分记忆 |
| fact-water / fact-capital-cn / list-3 | format brevity / list3 **原句包含**（v2 起） | 三题"过"含记忆 |
| def-ml | format one_sentence "机器学习" concept（v2 起） | 定义答案记忆 |
| en-fluency / zh-fluency | concise **原句/近句**（v2d 起，我加的） | v2d 三题复读改善含记忆成分 |
| reason-simple | helpful **完全一致**（v2 起） | reason 判过含记忆 |

**结论**：v2~v2d 的题库读数含记忆成分；**v1 的 16/18 是相对干净的读数**（v1 无 extras）。"按评测缺陷造数据"的方法本身没错（它是修复手段），但**必须做评测集去重**，否则指标退化为记忆测试。v2e 因此新增"去污"作为第 1 改动面。

## 6. 教训（入 `notes/lessons.md`）

1. **"按评测缺陷造数据"必须配评测集去重**：calibration/format extras 是修 v1 缺陷的主力，但把评测原句（2027 世界杯 / 7×6 / 水的化学式）带进了训练集——v2~v2d 的题库分含记忆成分，v1 的 16/18 反而是干净读数。**修复数据要按"能力/行为"写，不能按"题目"写**；有评测集的项目应把"extras vs 测试集去重断言"做成构建硬门（本次 `assert_no_eval_leak`）。
2. **去污后五项判据全过，证明 v2 时代的"能力不足"有一部分是假象**：math-mul/refuse/translate 在无记忆样本下靠泛化就能修（数学豁免 ×2 + 精确指令对是真实机制）。
3. **v2d 的三题复读改善含记忆成分**（concise 原句），v2e 去污后 en-fluency 0.208（v2d 0.371）反而更低——说明复读修复的主因是长答案压制 + concise 行为正例的**泛化**，记忆只占小头；两版并列才能分离这两个成分。
