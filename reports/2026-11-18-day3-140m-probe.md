## 3. micro-batch 变体对照（选型依据）

| 变体 | tokens/step | 峰值显存 | 纯训练 tok/s | 结论 |
|---|---|---|---|---|
| **bs8 × accum8**（采用） | 65,536 | 10.51 GB | **52,250** | 最快，余量最大 |
| bs10 × accum6 + expandable | 61,440 | 12.56 GB | 51,230 | 慢 2%，逼近上限，不用 |
| bs16 × accum4 + grad-ckpt | 65,536 | 8.84 GB | 40,449 | 重算代价 ~23%，不用 |
| bs12 + expandable | — | — | — | OOM（`1.46 GiB` 分配失败） |

**结论：主训练用 bs8×accum8**。"micro-bs 越大越快"在此不成立——bs8 的每步 token 数已足够喂满 SDPA，再大只是逼近显存上限（CE logits 三份副本，见 `2026-11-18-day3-framework.md` §3）。

## 4. 决策门①判定

> **判定：PASS。140M 实测 52,250 tok/s ≥ 35,000 tok/s（超出门限 49%）。按 D-01 全量启动 140M / 30 亿 token；100M / 20 亿兜底方案不启用。**

| 派生量 | 计算 | 值 |
|---|---|---|
| 3B 单程（纯训练） | 3.0e9 ÷ 52,250 | **15.9 h** |
| 加 eval/sample/ckpt 开销（实测 0.6%） | ×1.006 | **~16.0 h** |
| 总步数 | 3.0e9 ÷ 65,536 | **45,777 步** |
| 每步墙钟 | 65,536 ÷ 52,250 | **1.25 s** |
| ckpt 单件 / 总量 | 46 件 × 1.65GB（fp32 权重 + Adam 态） | **≈76 GB**（磁盘余 2.3TB） |
| 崩溃最大损失 | 1000 步 | **~21 min**（可接受） |

对照 PLAN §4.1 的前置表（35k→23.8h / 40k→20.8h）：实测 52k 落在"宽裕"档，**比原计划省 ~8h**，这个时间直接转成 Day 5~6 的 SFT/评测缓冲。

## 5. 首步锚 +0.170 的解读（不是数据 bug）

同词表三次实测：22.2M 字符级 +0.059（Day 1，不同词表）· 29.99M BPE **+0.081**（Day 2）· 140M **+0.170**（本次）。偏差随模型规模单调上升——初始 logits 的方差来自残差流累积（16 层比 8 层叠加更多小方差矩阵乘），**ln(V) 是"随机初始化"的极限值，不是逐模型的精确值**。判据用法：首步 loss 落在 `ln(V) + [0, 0.25]` 且绝对值不接近 0 即视为锚定正常；偏差 >0.5 或 <0 才停线查（数据/词表/取批）。

## 6. 140M 主训练定档（Day 4 可直接启动）

```bash
cd /home/zenz/projects/pretrain-lab
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
.venv-pre/bin/python -I tools/train.py \
  --run-name main140m --data-dir data/shards \
  --n-embd 768 --n-layer 16 --n-head 12 --block-size 1024 \
  --batch-size 8 --grad-accum 8 \
  --base-lr 6e-4 --warmup 500 --min-lr-frac 0.1 --weight-decay 0.1 --grad-clip 1.0 \
  --target-tokens 3e9 --max-minutes 1800 \
  --eval-every 500 --eval-iters 40 --eval-batch-size 16 \
  --sample-every 2000 --sample-tokens 80 \
  --ckpt-every 1000 --keep-ckpts 0 \
  --out-dir out/main140m \
  --notes "D-01/D-04 正式主训练：140M × 3B token"
```

| 项 | 定档 |
|---|---|
| 模型 | 137,847,552 参数（d768/L16/H12，tied，seq 1024，vocab 32k） |
| 数据 | 3,000,000,000 token（en 60%/zh 40%，6 片）；val = 固定 4M 窗口 |
| 优化 | lr 6e-4（nanoGPT 124M 同量级锚）· warmup 500（32.8M token，1.1%）· cosine→6e-5 · wd 0.1 · clip 1.0 · bf16 |
| 有效批量 | 65,536 tok/step（bs8×accum8）；**不改**（与探针同口径，吞吐读数可直接外推） |
| 存档 | 每 1000 步 `ckpt-XXXXXXX.pt` + `last.pt`；46 件 ≈76GB；G2 要求的 checkpoint 谱系 |
| 安全阀 | `--max-minutes 1800`（30h，正常 16h 触不到）；`--resume auto` 崩溃续训（已验证） |
| 监控节奏 | 每 20~30 min：`grep "tok/s\|\[val\]" logs/main140m-*.log` + `nvidia-smi`（温度/util/显存） |
