# 300M 探针 + **决策门③判定**

> 2026-11-23 · 预注册出处：内部 spec `specs/2026-11-23-probe-300m.md`（本地私有，不入库；门③判据跑前冻结：峰值 ≤14.0GB + 纯吞吐 ≥20k tok/s）· 证据 = 本件 + `2026-11-23-probe-300m.csv` + `...-probe-300m.log`；续训对账 = `...-probe-300m-seq50.log` + `...-probe-300m-resume.log`。**本探针不授权全量训练**（6B 全量需另立 spec，先解决数据缺口）。

## 1. 探针配置

d960 / L24 / H15（head_dim 64 · SwiGLU hidden 2560 · tied embeddings）· vocab 32,000 ·
T=1024 · **micro-bs 4 × grad-accum 16 = 65,536 tok/step** · AdamW(fused) lr 4e-4 · warmup 500 · bf16 ·
`PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` · 40 步（= 2,621,440 token）· 无 grad-ckpt · 无 compile。

## 3. 续训链路对账（AC5）

做法：50 步基准跑（`--ckpt-every 40`）→ 从 `ckpt-0000040.pt` `--resume` 复跑 41~50 步，同 step 对账。

| 项 | 基准（50 步） | 续训（40→50） |
|---|---|---|
| step 40 val | —（未开中途 eval） | 8.8716 |
| step 41~50 loss | 8.8723 / 8.8954 / 8.8066 / 8.8128 / 8.8165 / 8.7584 / 8.6832 / 8.6648 / 8.6254 / 8.6088 | 8.8723 / 8.8954 / 8.8066 / 8.8129 / 8.8165 / 8.7584 / 8.6831 / 8.6649 / 8.6254 / 8.6089 |
| step 50 val | **8.5796** | **8.5796** |
| 纯训练吞吐 | 26,197 tok/s | 26,104 tok/s |
| 退出 | EXIT:0 | EXIT:0 |

10 步 loss 全部一致到 4 位小数；4 步在末位差 1（日志舍入级），step 50 val 完全相同 → 续训链路 PASS。
ckpt 体积 3.31GB（fp32 权重 + Adam 态），`last.pt` 可载（本轮 resume 即验证）。

## 4. 决策门③判定

> **判定：PASS。** bs4 一次成功（无 OOM，bs2 回落档未启用）；峰值 **11.36GB ≤ 14.0GB**；纯吞吐 **26,232 tok/s ≥ 20,000**（超门限 31%）。

| 派生量（按实测） | 计算 | 值 |
|---|---|---|
| 6B 纯训练 | 6.0e9 ÷ 26,232 | **63.5 h**（spec 线性外推 69h / 24.3k；实测为外推的 108%） |
| 6B 加开销（0.6%） | ×1.006 | **~63.9 h** |
| 总步数 | 6.0e9 ÷ 65,536 | **91,553 步** |
| 单步墙钟 | 65,536 ÷ 26,232 | **2.50 s** |
| ckpt 单件 | fp32 权重 + Adam 态 | **3.31 GB**（每 1000 步 ≈92 件 ≈304GB；需 `--keep-ckpts` 或拉长间隔） |
| 显存余量 | 16.3GB − 11.36GB | **~4.9GB**（他项目常驻 1.8GB 时 ~3.1GB） |
| 3B 单程（参照 Chinchilla 10×） | 3.0e9 ÷ 26,232 | 31.8 h |

## 5. 已知边界（不因门③ PASS 而消失）

- **数据缺口未解**：库存 en ~4.7B + zh ~0.46B ≈ 5.2B < 6B；zh 已耗 72%，300M 全量守不住 40% 中文配比。全量立项 spec 必须先回答（en-heavy 配比 / 补下载 FineWeb-Edu + SkyPile zh）。
- **收益预期有限**：300M 仍低于 GPT-2 级；按 Chinchilla 比，数学/翻译能力块大概率仍不达标，门③ 只回答"本地能不能训"，不回答"训了会不会更好"。
- **外推口径**：63.5h 为纯训练墙钟；69h 级连续运行需续训闭环（已验）+ 磁盘预算（~300GB ckpt）。

## 6. 框架改动（spec §6 允许的 bugfix）

| 文件 | 改动 | 原因 |
|---|---|---|
| `tools/train.py` | `if args.eval_every > 0 and done % args.eval_every == 0` | 冻结命令含 `--eval-every 0`，原代码无 `>0` 守卫，首步即 `ZeroDivisionError`；`--sample-every` / `--ckpt-every` 本有守卫，只漏 eval |
| `tools/train.py` | resume 时打 `[resume-anchor]` 而非 `[anchor]` | 续训首 micro-step 的 loss 已在训练态，原代码只对 `--init-from` 分支，resume 会误报锚偏差 |

公开面零改动（HF / Release / Ollama / demo 未动）；产物在 `out/probe-300m-*`（gitignore）。

## 7. 结论与下一步

- **本地 16GB 可训 296M（bs4，11.36GB 峰值）**，吞吐 26.2k tok/s，6B 全量约 **63.5h**——距离"可立项"只差数据方案。
- 全量训练**未启动**，需另立 spec；v2g（翻译扩容 + calibration 修复）仍待用户拍板。
